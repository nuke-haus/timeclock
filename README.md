# Timeclock

A simple open-source time tracking tool with CSV export capabilities. 

# How To Use

Open the tool in your web browser: https://nuke-haus.github.io/timeclock/

## Suggested Setup

Get a browser you can dedicate to running the timeclock (ie. chrome or firefox). Set the downloads folder for that browser to a synced folder in your dropbox so that any downloaded files get dumped and insta-synced there.

The timeclock will automatically create a backup file in the download folder at midnight every day and force a clockout for any employee still clocked in. You can export all data from the timeclock PC and dump it in the dropbox folder as well, then import the file on the computer in the back office.

## Top Buttons

⏱️ - Main timeclock screen

📇 - Employee database screen (where you can edit people's data and punches)

🗓️ - Calendar screen where you can set the stat holidays for the year

📃 - Reports screen where you can generate a CSV with all of the employee timeclock punch data

🔒 - Click this to hide all of the top buttons and force the screen into the main timeclock screen. Refresh the webpage to undo the lock.
